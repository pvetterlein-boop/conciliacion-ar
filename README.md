# Dulce Crecer · Conciliación AR

Aplicación web de Babysmart SpA para conciliación de cuentas por cobrar.

- Frontend: GitHub Pages
- Autenticación y base de datos: Supabase
- Acceso: correo + contraseña, sin Google OAuth
- Auditoría: registro de acciones por usuario

Los datos operacionales se almacenan en Supabase; este repositorio contiene únicamente la interfaz web y configuración de publicación.
